Documentación del proyecto

LUMEN es un arcade web minimalista construido con JavaScript puro, Canvas 2D y Web Audio API, sin frameworks ni archivos externos de imagen o sonido. Esta página reúne los documentos de diseño y técnicos que acompañan al juego, en su versión navegable. Cada documento está disponible también en Markdown dentro del repositorio, y en PDF y Word para entrega.
